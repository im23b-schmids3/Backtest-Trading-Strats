# smithers eject

Copy a pack workflow and its UI, prompts, and libraries into the local .smithers pack.

## Arguments

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `spec` | `string` | yes | Pack workflow in the form <pack>:<workflow> |
