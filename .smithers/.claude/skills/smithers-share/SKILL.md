# smithers share

Add this project's workflow pack to awesome-smithers and open a pull request.

## Options

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--repo` | `string` |  | Override the awesome-smithers repository (owner/name) |
| `--dryRun` | `boolean` | `false` | Print the registry entry and diff without pushing |
