Terminal execution semantics

  • HARD_FLAT_BERLIN: at 22:45 Berlin, cancel working orders, block later entries, and liquidate long at the first causally executable native bid or short at the native ask, with normal adverse exit slippage.
  • DATA_GAP_3S_FORCE_FLAT: a fresh native BBO returning at or before exactly 3.000 seconds resumes normal monitoring. A longer gap exits at the last valid native BBO; no stop/target fill is invented inside the unavailable interval.
  • SOURCE_END_FORCE_FLAT_LAST_VALID_BBO: source end exits at the last defensible native bid/ask and records source, decision, and BBO-age timestamps.
  • UNPRICED_SOURCE_INTEGRITY_FAILURE: no price is invented when a defensible native BBO does not exist.
  • Maintenance: an open position at the evidenced exchange-maintenance start is a fatal regression, not an unresolved result.

All entered trades must terminate as TARGET, STOP, HARD_FLAT_BERLIN, DATA_GAP_3S_FORCE_FLAT, or SOURCE_END_FORCE_FLAT_LAST_VALID_BBO. Successful configurations require unresolved = 0.
