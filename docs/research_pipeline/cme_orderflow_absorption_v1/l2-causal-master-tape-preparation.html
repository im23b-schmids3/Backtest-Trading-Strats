Causal ordering and compression

The stable key is (timestamp_ns, stream_priority, source_index), with native MES priority 0, ES priority 1, and calendar boundaries priority 2. Equal-time MES observations therefore precede ES exactly as in the frozen replay merge loop.

Unchanged ordinary BBO observations are omitted only when they cannot affect state. Every ES execution remains. Every BBO change remains. The first ordinary observation at or after each interaction's possible confirmation plus 2ms remains as an indexed entry probe. Stop/target paths need only BBO changes; hard-flat rows carry the last causal quote and its true source timestamp. This avoids an event-by-interaction Cartesian expansion.

Counterfactual coverage

  • Low-quality and primitive-rejected interactions are registered before filtering and receive the same confirmation window and session path index.
  • Originally position-blocked interactions are not assigned permanent outcomes. Each later configuration creates an independent chronological portfolio state and can replay them if unblocked.
  • Thresholds 0.35, 0.40, 0.45, 0.50, 0.55, and 0.60 require zero further DBN scans.
  • Alternative legal five-component weights require zero further DBN scans because raw components and frozen penalty inputs are stored.
  • No existing trade ledger is read or used as a hypothetical outcome source.
