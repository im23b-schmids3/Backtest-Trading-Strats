# First real strategy run

The checked-in F2 demo uses `SPX` with an explicitly declared `SPY` proxy and
the local `data/v11_5_proxy_raw/SPY_1h.parquet` dataset. It demonstrates intake,
approval, adapter discovery, real trade artifacts, B.5, bounded Phase C, and a
final report. Its confidence is `REAL_LOCAL_DATA_DEMONSTRATION`; it is not
live-market validation and must not be used as a trading authorization.
