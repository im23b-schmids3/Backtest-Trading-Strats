# Portfolio eligibility

A member must have an approved immutable specification, frozen Phase C
candidate hash, verified B.5 integrity evidence, completed chronological
validation, and an allowed Phase C classification. Phase D must be accepted for
prop portfolios; own-capital or insufficient-prop evidence requires an explicit
mode and is classified exploratory. Rejected prop classifications, changed
hashes, missing evidence, and technical failures are blocked. Eligibility is
reevaluated at portfolio creation and recorded in the journal.
